# Install or share the Super MD skill

Copy the complete `super-md/` folder into your agent's skills directory (for Codex, `~/.codex/skills/`). Keep `SKILL.md`, `references/` and `assets/` together. Reload skill discovery in the client if required; installation does not automatically add a skill to an already supplied context.

Native builds include `dist/super-md-skill.zip`, containing the complete portable folder. Extract that archive into the skills directory. It contains general instructions and no personal profile, connector URLs or credentials. Optional personal defaults belong in `super-md/references/local-preferences.md` and should remain local.

The app's private MCP setup guide and this public skill package serve different purposes. Keep the private setup guide private; share the portable skill ZIP.
